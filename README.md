# DataDrive_Conv ⚡
> Projeto de Modelagem e Simulação de Conversores de Potência

Este repositório contém os estudos, modelagens matemáticas e simulações desenvolvidas para conversores estáticos de potência, com foco inicial no **Conversor Buck** utilizando a técnica de **Espaço de Estados**.

## 📂 Estrutura do Projeto

De acordo com a organização do workspace:

* **📁 BUCK**: Diretório principal dos estudos do conversor abaixador.

* **📄 .all-contributorsrc.ipynb**: Controle de contribuições e histórico do projeto.

## 🛠️ Tecnologias e Ferramentas

* **Python 3.x**: Processamento numérico e simulação.
* **Jupyter Notebook**: Ambiente de desenvolvimento interativo.
* **Quarto**: Ferramenta para renderização de relatórios técnicos em HTML/PDF.
* **Bibliotecas**: `numpy`, `scipy.signal`, `matplotlib`.
* **MATlab/simulink**: simulação.
